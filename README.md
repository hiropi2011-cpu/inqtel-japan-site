- コンセプト：AIエージェントは“ツール”ではなく、現場で動く“戦力”
- ターゲット：中小企業（従業員10〜50人規模）の経営者
- 構成：Hero / 01 コンセプト / More than one / 02 3つの価値 / 03 できること / 04 導入の流れ / 05 自社実践 / 06 会社概要 / 07 お問い合わせ
